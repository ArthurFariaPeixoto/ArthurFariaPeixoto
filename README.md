### 💻 Projetos em Destaque

* 💬 **Plataforma Talkie (Full Stack)**
  * [Talkie Front-end](https://github.com/ArthurFariaPeixoto/talkie-frontend): Interface moderna de uma plataforma de comunicação em tempo real construída com **React**. Explora o gerenciamento de estados, consumo de APIs e componentes estilizados para proporcionar uma experiência fluida de usuário.
  * [Talkie Back-end](https://github.com/ArthurFariaPeixoto/talkie-backend): API responsável por sustentar as regras de negócio e a comunicação em tempo real da aplicação. Focada em escalabilidade e estruturação de rotas.

* 💾 **[Esteganografia em C](https://github.com/ArthurFariaPeixoto/Esteganografia_C)**
  Algoritmo desenvolvido em linguagem **C** focado na ocultação de mensagens e informações dentro de arquivos de mídia. Um projeto que explora conceitos de baixo nível, manipulação de arquivos binários e estruturas de dados.

* 🎮 **[Don't Waste Your Ammo](https://github.com/ArthurFariaPeixoto/Dont_Waste_Your_Ammo)**
  Projeto focado no desenvolvimento de jogos, aplicando conceitos fundamentais como lógica de jogo, gerenciamento de recursos (*munição*) e mecânicas interativas para criar um desafio envolvente.
